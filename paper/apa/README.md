# APA 7th Edition Research Paper

This directory contains the synthesized APA 7th Edition formatted research paper, compiled from the original research proposal document and the iCreate 2026 conference paper.

## LaTeX Compilation Guide

To compile the `thesis_apa.tex` document into a PDF, you can use one of the following methods depending on your LaTeX environment.

### Option 1: Using `latexmk` (Recommended)
`latexmk` automatically runs pdfLaTeX and Biber the necessary amount of times to resolve all cross-references and bibliography entries.

Run the following command in this directory:
```bash
latexmk -pdf thesis_apa.tex
```

### Option 2: Manual Compilation
If you don't have `latexmk`, you will need to manually run `pdflatex` and `biber` (for the APA bibliography) in the correct sequence to ensure citations are generated properly.

1. Run pdfLaTeX first to generate the auxiliary files:
   ```bash
   pdflatex thesis_apa.tex
   ```
2. Run Biber to process the bibliography (`references_apa.bib`):
   ```bash
   biber thesis_apa
   ```
3. Run pdfLaTeX again to include the bibliography and resolve citations:
   ```bash
   pdflatex thesis_apa.tex
   ```
4. Run pdfLaTeX one final time to finalize all formatting and cross-references:
   ```bash
   pdflatex thesis_apa.tex
   ```

### Cleaning Up Auxiliary Files
After compiling, you can clean up the auxiliary files generated by LaTeX by running:
```bash
latexmk -c
```
*(Note: A comprehensive `.gitignore` has been set up at the root level of the repository to keep these files untracked from Git.)*
